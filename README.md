# FIRETRACE-Forest-Integrated-Real-Time-Environmental-Forensic-Evidence-System-
Platform berbasis web terintegrasi yang menyajikan data pemantauan kondisi lingkungan secara real-time, mendeteksi indikasi kebakaran hutan dan lahan berbasis fuzzy logic, serta merekam kronologi data secara ilmiah dengan lapisan integritas kriptografis guna mendukung rekonstruksi peristiwa dan pembuktian hukum.
