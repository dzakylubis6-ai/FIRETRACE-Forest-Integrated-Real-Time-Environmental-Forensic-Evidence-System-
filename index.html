Matriks Atribusi Pemicu: Faktor Alamiah (BMKG) vs Aktivitas Manusia

Standar ilmiah dan forensik untuk membedakan sumber pemicu kebakaran hutan secara akurat.

🌿 Indikator Penyebab Alami (Sumber: BMKG & Parameter Klimatologi)

  • Aktivitas Petir (Cloud-to-Ground): Tercatat sambaran petir positif/negatif di koordinat titik awal dalam radius 1 km sebelum T0.
  • Indeks Kekeringan (KBDI / FFWI): Nilai Keetch-Byram Drought Index > 600 atau Hari Tanpa Hujan > 21 hari.
  • Puncak Suhu & RH Ekstrem: Suhu udara tinggi bertepatan dengan kelembapan relatif rendah.

👥 Indikator Aktivitas Manusia / Kesengajaan (Antropogenik)

  • Pola Multi-Node Berjajar: Beberapa node sensor terpicu serentak dalam garis lurus/terpisah (pola pembukaan lahan).
  • Ketiadaan Sambaran Petir BMKG: Tidak ada catatan petir di sekitar lokasi sebelum waktu T0.
  • Laju Asap Cepat (Rate of Change): Konsentrasi asap MQ135 meningkat drastis secara instan.

Arsitektur Sistem & Perangkat Keras IoT (FIRETRACE)

Diagram alur end-to-end dari sensor lapangan hingga penyimpanan forensik terenkripsi.

🔄 Alur Komunikasi Data (Data Pipeline)

1. Layer Sensor Lapangan (Edge Computing):
Menggunakan ESP32 microcontroller yang membaca sensor DS18B20 (Suhu), BME280 (Kelembapan/RH), MQ135 (Gas Asap), UVTRON (Deteksi Nyala Api UV), dan Anemometer.
2. Layer Transmisi & Gateway:
Data telemetri dikirimkan secara nirkabel menggunakan protokol MQTT/LoRaWAN dan backup seluler 4G/LTE langsung ke Cloud Server.
3. Layer Pemrosesan AI & Atribusi Pemicu:
Sistem secara cerdas menganalisis apakah anomali berasal dari Sambaran Petir BMKG (Alami) atau Pola Multi-Node Berjajar (Ulah Manusia).
4. Layer Penyimpanan Eviden (Cloud Camera & DCoC):
Snapshot kamera di-upload otomatis ke AWS S3 / Firebase Cloud Storage, lalu dikunci dengan enkripsi SHA-256 Digital Chain of Custody untuk keperluan BAP Pro-Justitia.
